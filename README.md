# SirusChatWheel

Колесо чата для **WoW Sirus 3.3.5a** на Lua 5.1.
Удерживайте **Y**, выберите направление мышью и отпустите клавишу,
чтобы отправить выбранную фразу.

- Восемь настраиваемых секторов.
- 12 текстовых фраз и голосовые записи WAV, MP3 и OGG из общего набора выпуска.
- Отправка в `/raid` или `/say`.
- Синхронизация голосовых фраз между игроками с аддоном и одинаковыми файлами.
- Лимит голосовых фраз: два звука за скользящие 30 секунд.
- Персональный мут звуков: недавние отправители, ввод ника и сохранённый список на вкладке «Игроки».
- Выбор от исходного положения мыши, без переноса курсора в центр.
- Проверка новых версий на GitHub через внешний скрипт.
- Один полный архив с готовым набором звуков для установки и обновления обычным копированием в AddOns.

`/scw` открывает настройки, `/scw test` показывает колесо без отправки,
`/scw update` показывает результат последней проверки версии.

Готовые версии доступны в [Releases](https://github.com/mosf1c/SirusChatWheel/releases).

Голосовые записи не передаются по сети: получателям нужны одинаковые файлы.
