SIRUS CHAT WHEEL 1.4.0
Колесо чата для WoW Sirus 3.3.5a / Lua 5.1.

НОВОЕ В 1.4.0
Вкладка «Игроки»: список недавних отправителей с последней голосовой фразой,
заглушение по кнопке или введённому нику и список с кнопкой «Вернуть звук».
Мут применяется сразу, убирает ожидающие записи этого игрока и сохраняется
между запусками. Текстовые сообщения остаются видны; чёрный список WoW
не изменяется. Уже начавшаяся запись доигрывает до конца.

ЗВУКИ ИЗ 1.3.0
Добавлена голосовая фраза «Короля не убить». Все три записи приведены
к близкой громкости; «Киси-киси» и новая фраза усилены, «Песик» изменён
минимально. В комплекте WAV PCM 16 бит, 44100 Гц, моно.
После изменения аудиофайлов другим игрокам тоже нужен этот выпуск,
чтобы проверка содержимого файлов разрешала совместное воспроизведение.

УСТАНОВКА И ОБНОВЛЕНИЕ
1. Полностью закройте игру.
2. Скачайте полный архив SirusChatWheel-X.Y.Z.zip из Releases:
   https://github.com/mosf1c/SirusChatWheel/releases.
3. Распакуйте его и перенесите папку SirusChatWheel в Interface\AddOns
   внутри папки игры. При обновлении объедините папки и согласитесь
   на замену файлов. Удалять старую папку не требуется.
4. Запустите игру. При первой установке включите аддон на выборе персонажа.

Правильный путь: Interface\AddOns\SirusChatWheel\SirusChatWheel.toc.
Один и тот же полный архив подходит и новым игрокам, и для обновления.
Код, все звуки, названия, каталог и кэш уже находятся в архиве.
Установщик и пересборка каталога игроку не нужны.
Настройки секторов, канала, размера и другие параметры остаются в WTF.
Новые записи появляются в списке выбора фраз. Существующие назначения
сохраняются, пока запись с тем же именем и путём входит в новый выпуск.
Исключённая или переименованная автором запись оставляет пустой сектор.

УПРАВЛЕНИЕ
Удерживайте Y, сдвиньте мышь в направлении фразы и отпустите Y.
Выбор считается от положения курсора при нажатии; переносить его в центр
не требуется. Обычный курсор скрывается. Возврат в зону отмены, Esc или
щелчок мыши отменяют отправку. Открытая строка ввода не перехватывается.
Колесо работает в бою; назначение новой клавиши при необходимости откладывается.

НАСТРОЙКИ
/scw открывает настройки. Для каждого из восьми секторов сначала идут
12 текстовых фраз, затем голосовые записи из текущего выпуска.
Значок динамика обозначает голосовую запись. Кнопка > даёт локальное
прослушивание без чата и расхода лимита. «Очистить» оставляет сектор пустым.
Изменения применяются кнопкой «Сохранить» или стандартной «ОК».
Исключение — мут на вкладке «Игроки»: действует сразу, отмена и сброс
других настроек его не убирают. Список общий для аккаунта; ник без сервера
относится к текущему серверу. Недавние отправители хранятся до перезапуска.
Настройки доступны также через Esc → Интерфейс → Модификации.
По умолчанию выбран /raid; переход на /say вне рейда выключен.

ГОЛОСОВЫЕ ФРАЗЫ
Принятая голосовая фраза публикует название в /raid или /say и передаёт
скрытое подтверждение аддона. Просто написать название в чат недостаточно.
Получателям нужны аддон и одинаковые звуковые файлы. Аудио по сети
не передаётся; для новых записей другим игрокам тоже нужен новый выпуск.
Содержимое файлов сверяется, повторы одного действия отсекаются.
Для /say используется служебный шёпот; его должен разрешать сервер.

Общий лимит голосовых отправок: два звука за скользящие 30 секунд.
Третья попытка не отправляет чат, скрытую команду или звук и показывает
красное оставшееся время. /reload и сохранение настроек лимит не обнуляют.
Текстовые фразы не расходуют этот лимит. Входящие записи ставятся в очередь.

КОМАНДЫ
/scw или /chatwheel — настройки.
/scw test — колесо без отправки чата и звуков.
/scw bind — назначить Y.
/scw status — версия, клавиша и канал.
/scw sounds — число записей в текущем выпуске.
/scw update — результат последней проверки GitHub.
/scw close — отменить выбор.

ПРОВЕРКА ОБНОВЛЕНИЙ
Check-Updates.cmd проверяет последний стабильный Release репозитория
mosf1c/SirusChatWheel. Вводить адрес при первой проверке не требуется.
Если игра открыта, после проверки выполните /reload и /scw update.
При входе аддон сообщает о более новой версии по проверке не старше суток.
Ошибка сети и отсутствие релиза не выдаются за отсутствие обновлений.
Проверка только сообщает о выпуске; его установка — обычное копирование.
Start-ChatWheel.cmd необязательно проверяет версию и запускает WoW.exe,
используя готовый каталог из архива. Можно запускать игру лаунчером Sirus.

НАСТРОЙКИ НА ДИСКЕ
WTF\Account\<аккаунт>\SavedVariables\SirusChatWheel.lua.
Игра сохраняет их при /reload или выходе; эта папка не входит в архив аддона.
Привязки клавиш сохраняются в выбранном наборе WoW.

ДОБАВЛЕНИЕ ЗВУКОВ АВТОРОМ ВЫПУСКА
Набор общий для всех игроков. В исходниках положите WAV, MP3 или OGG
в Sounds; подпапки и русские имена поддерживаются. Отдельные подписи
задаются в SoundNames.json: ключ — путь относительно Sounds с /,
значение — название в чате. Для смены подписи не переименовывайте файл:
так сохранится назначение сектора у пользователей.
Sounds и SoundNames.json входят в Git. Catalog.lua и Media\Cache генерируются.

При сборке python tools/build_release.py автоматически включает все звуки,
создаёт готовый каталог и кэш и выпускает один полный ZIP в dist.
После проверки публикуйте этот ZIP в Release с тегом vX.Y.Z.
В репозитории настроена автоматическая проверка и публикация по тегу:
при отправке аннотированного тега vX.Y.Z в GitHub процесс Release
собирает ZIP и добавляет его в Releases. Порядок — tools/RELEASING_RU.md.
Update-Sounds.cmd нужен автору для локальной пересборки каталога; после неё
в игре нужен /reload. Watch-Sounds.cmd отслеживает изменения для разработки.
Игрокам эти действия для установки и обновления выполнять не требуется.

назначения из SavedVariables, лимит и удаление звука при оставшемся старом файле.
Проверены мут в рейде и /say, очередь, русские ники, список и сохранение мута.

в игре. Включите общий звук и звуковые эффекты WoW.
