SIRUS CHAT WHEEL 1.2.4
Готовый аддон для WoW 3.3.5a / Sirus. Библиотеки аддонов не нужны.
Две записи уже включены: «Киси-киси, мяу-мяу» и «Песик-песик, ав-ав-ав».

ДОБАВЛЕНО В 1.2.4
Проверка GitHub Releases: Check-Updates.cmd. При первом запуске укажите
URL публичного репозитория. Адрес сохраняется в UpdateConfig.json.
Проверка не устанавливает обновления и не меняет звуки или каталог.
После проверки выполните /reload; /scw update показывает её результат.
При входе сообщается о более новой версии по проверке не старше суток.
Start-ChatWheel.cmd также проверяет версию перед запуском игры, когда URL
уже настроен. При обычном запуске через лаунчер используйте проверку вручную.
Сетевую проверку выполняет внешний PowerShell, результат читает Lua-аддон.
Свежая версия берётся из стабильного Release с тегом vX.Y.Z или X.Y.Z.
Если GitHub недоступен или релиз отсутствует, проверка сообщает об ошибке.
Для обновления используйте архив -update.zip, сохраняющий ваши записи.
URL репозитория пока не задан; публикация на GitHub пользователем ещё нужна.

ИСПРАВЛЕНИЕ В 1.2.3 (СОХРАНЕНО)
Исправлена синхронизация двух голосовых фраз в /say. Обе принятые отправки
теперь сохраняются для скрытого подтверждения в течение шести секунд;
задержка ответа больше не теряет первую запись. Два названия, полученные
менее чем за секунду, тоже обрабатываются. Повторы пакетов не играют заново.
Для этого исправления отправителю и получателю нужна версия 1.2.3.

ИСПРАВЛЕНИЕ В 1.2.2 (СОХРАНЕНО)
Исправлена загрузка MP3: прежний фильтр расширений ошибочно отбрасывал
цифру 3, поэтому утилита находила MP3, а аддон не включал их в список.
При обновлении с 1.2.1/1.2.2 используйте архив с окончанием -update.zip.
Он не содержит Sounds, SoundNames.json, Catalog.lua и Media\Cache,
поэтому сохраняет ваши записи, названия и каталог. Затем выполните /reload.
Если состав звуков не менялся, запускать Update-Sounds.cmd не требуется.

УСТАНОВКА И ОБНОВЛЕНИЕ
1. Полностью закройте игру.
2. Распакуйте папку SirusChatWheel в Interface\AddOns внутри папки игры.
   Правильный путь: Interface\AddOns\SirusChatWheel\SirusChatWheel.toc.
   Дополнительной вложенной папки SirusChatWheel быть не должно.
3. Для обновления распакуйте архив -update.zip поверх прежней версии.
   Если используете полный архив, не заменяйте Sounds, SoundNames.json,
   Catalog.lua и Media\Cache. Не удаляйте настройки в WTF.
   После изменения состава Sounds запустите Update-Sounds.cmd.
4. Включите Sirus Chat Wheel на экране выбора персонажа. Если требуется,
   включите загрузку устаревших модификаций.
5. При самой первой установке Y назначается автоматически. При обновлении
   прежнее назначение клавиши, канал и настройки сохраняются.

КАК ПОЛЬЗОВАТЬСЯ
Удерживайте Y, сдвиньте мышь в направлении нужной фразы и отпустите Y.
Обычный курсор скрывается; центральный указатель и подсветка показывают выбор.
Выбор считается от положения мыши в момент нажатия Y. Возвращение мыши
в исходную точку, Esc или любой щелчок отменяют отправку.
При открытой строке ввода текста Y не перехватывается. Колесо работает в бою.
Физический курсор не переносится в центр: стандартный API 3.3.5 этого
не позволяет. Ближе к краю окна движение наружу ограничено границей окна.

Шрифт колеса увеличен на 40%, фразы расположены ближе к кольцу.
В версии 1.2.1 значок динамика в колесе выровнен по вертикальному центру
всей подписи: у двухстрочного текста он находится между строками.
Нижней подписи с каналом и инструкцией нет. Пустой сектор не имеет надписи
и при отпускании клавиши ничего не отправляет.

НАСТРОЙКИ И ВЫБОР ФРАЗ
Введите /scw или откройте Esc → Интерфейс → Модификации → Sirus Chat Wheel.
Вкладка «Фразы»: восемь положений колеса, начиная сверху по часовой стрелке.
Нажмите на фразу — откроется прокручиваемый список. Сначала идут текстовые:

Хорошо сыграно!
Спасибо!
Прошу прощения
Подтверждаю
Не сдавайтесь!
Тяжелый пул
Помогите!
Назад!
Атакуем!
Закончилась мана
Полечите
GG, WP!

Ниже идут все голосовые записи из обновлённого каталога. Число записей
в списке не ограничено фиксированным набором. Список прокручивается колесом
мыши или полосой справа. У голосовых записей значок динамика слева:
в списке, на кнопке выбранной фразы и в самом колесе.
«Очистить» оставляет сектор пустым. Кнопка > рядом с выбранной записью
проигрывает её только у вас, без чата и расходования лимита отправки.

Вкладка «Параметры»: /raid или /say, переход на /say вне рейда, скрытие
курсора, входящие звуки, размер колеса, чувствительность и зона отмены.
«Назначить Y» повторно назначает клавишу; в бою назначение откладывается.
Вкладка «Звуки» содержит инструкцию по папке и обновлению каталога.
Изменения применяются кнопкой «Сохранить» или стандартной «ОК».
«Отмена» отклоняет несохранённые изменения. «По умолчанию» подготавливает
стандартные значения; подтвердите их сохранением.
По умолчанию выбран /raid, переход на /say вне рейда выключен.

СВОИ ЗВУКИ И УДАЛЕНИЕ ФАЙЛОВ
Папка для записей: Interface\AddOns\SirusChatWheel\Sounds.
1. Положите в неё WAV, MP3 или OGG. Можно создавать подпапки. Количество
   записей не задано заранее. Несовместимое кодирование игра не воспроизведёт;
   самый надёжный вариант для старого клиента — WAV PCM 16 бит, 44100 Гц.
2. Запустите Update-Sounds.cmd двойным щелчком. После сообщения об обновлении
   закройте окно. Это встроенный Windows PowerShell, отдельная установка
   Python или другого ПО не требуется; нужен Windows PowerShell 5.1 или новее.
3. В игре выполните /reload либо запустите игру, затем выберите запись в /scw.

Название по умолчанию — имя файла без расширения; подчёркивания заменяются
пробелами. Русские имена поддерживаются. Если хотите отдельное название,
задайте его в SoundNames.json: ключ — имя файла относительно Sounds
(для подпапок используйте /), значение — отображаемый текст. Формат JSON.

После удаления или переименования записи обновите каталог и выполните /reload.
Запись исчезнет из списка, а использовавшие её секторы станут пустыми.
Старая текстовая фраза не подставляется. Возвращение удалённого файла
не назначает его в очищенный слот автоматически: выберите его снова.
Изменение содержимого файла с прежним именем сохраняет назначение сектора.

АВТОМАТИЧЕСКОЕ ОБНОВЛЕНИЕ
WoW 3.3.5 не даёт Lua-аддону читать список файлов папки. Поэтому каталог
обновляет внешняя утилита; один /reload без обновления каталога не обнаружит
новые или удалённые файлы.

Watch-Sounds.cmd обновляет каталог и отслеживает папку, пока окно открыто.
Можно запускать игру обычным лаунчером Sirus. После изменения папки дождитесь
сообщения об обновлении и выполните /reload. Ctrl+C останавливает наблюдение.
Start-ChatWheel.cmd сначала обновляет каталог, затем запускает WoW.exe
из папки игры и следит за Sounds до закрытия клиента. Для обновлений Sirus
используйте его обычный лаунчер; если WoW.exe называется иначе, используйте
Watch-Sounds.cmd и запускайте игру привычным способом.

Catalog.lua и Media\Cache создаются автоматически. Не добавляйте записи
в Cache и не редактируйте Catalog.lua вручную. В Cache находятся копии
с короткими латинскими именами для совместимости старого клиента.
Исходные записи из Sounds утилита не удаляет и не переименовывает.

ОТПРАВКА, ЛИМИТ И ЗВУК У ДРУГИХ ИГРОКОВ
Принятая голосовая фраза играет у вас и публикует название в выбранном чате.
Лимит общий для всех голосовых записей: не больше двух отправок за любые
30 секунд. Третья попытка не отправляет чат или скрытую команду и не играет
звук. На экране появляется красное «Использовать звуки можно через N с».
Каждое использование истекает через 30 секунд отдельно. /reload, сохранение
настроек и «По умолчанию» не сбрасывают оставшийся лимит. Обычные текстовые
фразы в этот лимит не входят; у них отдельный интервал 0,8 секунды.

Воспроизведение у других игроков запускается отдельными скрытыми сообщениями
аддона. Простого написания названия записи в чат без отправки из колеса
недостаточно. В /raid команда передаётся участникам рейда; в /say аддоны
ближайших игроков запрашивают скрытое подтверждение настоящего выбора звука.
У соседей вне рейда это тоже работает, если сервер разрешает стандартные
служебные сообщения аддонов в шёпоте. Скрытый пакет не является строкой чата.
Входящая сторона также ограничивает одного отправителя двумя звуками за 30 с
и отсекает повтор одного действия. Записи становятся в короткую очередь,
чтобы не звучать одновременно.

Для MP3 у других игроков тоже нужна версия 1.2.2 или новее.
Обмен WAV совместим с версиями 1.2.0 и 1.2.1. У всех участников должны быть
те же исходные файлы с одинаковыми именами и относительными путями.
Содержимое файла сверяется: чужая запись с тем же
именем не будет случайно воспроизведена. Аудио по сети не передаётся.
Аддоны 1.0/1.1 не поддерживают новый протокол; для совместной работы обновите
их тоже. Проверка не является защитой от специально изменённых аддонов.
В игре должны быть включены общий звук и звуковые эффекты. Громкость не меняется.

ГДЕ НАСТРОЙКИ
WTF\Account\<учётная запись>\SavedVariables\SirusChatWheel.lua.
Они общие для учётной записи и записываются WoW при /reload или выходе.
Привязки клавиш сохраняются в текущем наборе WoW: общем или для персонажа.
При обновлении с 1.0/1.1 прежние фразы, канал и другие значения переносятся.
Старые пользовательские тексты остаются назначенными; новый список предлагает
фиксированные 12 текстов и записи из папки.

КОМАНДЫ И ПРОВЕРКА В ИГРЕ
/scw или /chatwheel — настройки.
/scw test — колесо для проверки без отправки сообщений и звуков.
/scw bind — назначить Y.
/scw status — версия, клавиша и канал.
/scw sounds — число записей и напоминание об обновлении папки.
/scw update — результат последней внешней проверки GitHub.
/scw close — закрыть колесо без отправки.
Другую клавишу можно выбрать в Esc → Назначение клавиш → Sirus Chat Wheel.

Сначала проверьте /scw test и все восемь направлений. Затем выберите /say,
сохраните настройки и отправьте обычную фразу. Для проверки синхронизации
выберите запись и используйте вторую копию аддона у соседнего игрока.
После двух звуков третья попытка должна показать красное оставшееся время.
Для проверки удаления: уберите назначенный файл из Sounds, обновите каталог,
выполните /reload — слот должен стать пустым.

ПРОВЕРКИ СБОРКИ
См. TEST_REPORT_RU.txt. В текущей проверке код исполнен настоящим Lua 5.1
с имитацией API WoW, утилита — Windows PowerShell 5.1 в Windows.
Проверены несколько окружений игроков, быстрые и задержанные подтверждения
/say, MP3, удаление и переименование. Игрового клиента Sirus в среде
сборки нет; имитация API не заменяет проверку непосредственно в игре.
