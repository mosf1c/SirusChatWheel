УСТАНОВКА И СБОРКА (СОХРАНЕНО)
Один полный архив для установки копированием и обновления с заменой файлов.
Все WAV/MP3/OGG из авторской папки Sounds и SoundNames.json входят в выпуск.
Сборщик каждый раз создаёт каталог и кэш в чистой временной папке.
Установщик удалён. Подготовка каталога выполняется автором, а не игроками.
Sounds и SoundNames.json теперь версионируются в Git. Для аудио и текстур
заданы бинарные атрибуты Git, исключающие преобразование окончаний строк.
Проверка GitHub по умолчанию использует mosf1c/SirusChatWheel.
Дополнительный запуск игры не пересобирает готовый каталог.

ПРОВЕРКИ УСТАНОВКИ КОПИРОВАНИЕМ
- Ровно один полный ZIP; правильная папка и готовый каталог; CRC без ошибок.
- Новая установка: обычная распаковка в Interface/AddOns; запуск Lua без
  выполнения установщика или утилиты каталога на стороне игрока.
- Добавление автором WAV в русской подпапке и MP3 с расширением .MP3:
  оба исходника, подписи и готовые кэши входят в следующий ZIP.
- Полное обновление обычной распаковкой с заменой файлов: новые записи сразу
  присутствуют в списке, обновлённая подпись и содержимое заменяют прежние.
- Кэши побайтно совпадают с новыми исходниками. Обе записи доходят до
  имитированного PlaySoundFile. Для MP3 используются синтетические MPEG-фреймы:
  декодирование настоящим клиентом эта проверка не подтверждает.
- Назначения существующих записей сохраняются по стабильным ID путей.
- Текстовые сектора, канал, размер, чувствительность, зона отмены и оставшийся
  лимит из SavedVariables сохраняются. Сам файл WTF не меняется копированием.
- Локальный UpdateConfig.json не входит в ZIP и сохраняется при объединении.
- Удалённый из нового каталога звук не появляется в списке и очищает сектор,
  даже если обычное объединение папок оставило его прежние файлы на диске.
- Остальные назначения при этом сохраняются.
- Необязательный запуск игры с готовым каталогом не возвращает устаревшие
  файлы в список. Запуск процесса игры имитируется и не выполняется реально.
- Неаудиофайлы не добавляются в Sounds выпуска. Исходный SoundNames.json
  не меняется при сборке.

ОСНОВНЫЕ РЕГРЕССИОННЫЕ ПРОВЕРКИ
- TOC, ADDON_LOADED, PLAYER_LOGIN, назначение Y и выполнение Bindings.xml.
- Восемь направлений, исходное положение мыши и зона отмены.
- Отпускание повторно считывает мышь; курсор восстанавливается.
- Тестовый режим не отправляет; ввод текста, бой и отмена щелчком.
- 12 текстовых вариантов перед звуковыми; восемь подписей со шрифтом x1,4.
- Динамик слева по вертикальному центру всей подписи; нижней инструкции нет.
- Применение настроек и восстановление значений по умолчанию.
- Два разрешённых звука, блокировка третьего без чата/команды/аудио;
  красная ошибка, независимое истечение отправок, сохранение лимита.
- /raid и скрытые пакеты между независимыми окружениями игроков.
- /say: две быстрые записи, задержанные подтверждения и повтор одной записи.
- Один текст в чате не запускает звук. Повтор пакета, чужой участник и
  устаревшее действие отклоняются. Приём можно отключить.
- Ошибка отправки чата откатывает расход лимита и подтверждения.
- Windows PowerShell генерирует каталог с русскими путями, кавычками,
  слешами и MP3; переименование/удаление очищают назначение и прежний кэш.
- Проверка GitHub: сравнение чисел версии, нормализация URL, сохранение
  явного адреса, работа без конфигурации с адресом издателя, устаревший
  результат, ошибка сети, prerelease, некорректный тег и посторонний домен.
- Ответ API не становится исполняемым Lua-кодом. Проверка не заменяет
  файлы звуков, каталога, названий или кода и не отправляет сообщения WoW.

ПРЕДЕЛЫ ПРОВЕРКИ
Sirus недоступен. Не проверены реальное декодирование аудио, аппаратный
курсор, визуальный результат в игровом клиенте, защищённые пути исполнения
и разрешение служебного шёпота сервером Sirus.
Новые тестовые записи существуют только во временных каталогах стенда.
В текущий реальный выпуск входят нормализованные Cat.wav, Dog.wav и King.wav.
Сборщик автоматически включает следующие добавленные автором записи.
Публикация на GitHub в этой проверке не выполнялась.
