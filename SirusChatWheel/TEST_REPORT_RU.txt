Sirus Chat Wheel 1.2.4 — проверка сборки, 17.10.2026

РЕЗУЛЬТАТ ТЕКУЩЕЙ ПРОВЕРКИ
80 из 80 автоматических проверок прошли.
Среда: Windows, Lua 5.1 через lupa.lua51, Windows PowerShell 5.1.19041.6456.
Все Lua-файлы из TOC загружаются и исполняются. API WoW, виджеты,
события, часы, чат и сеть имитируются; отдельные игроки имеют независимые
Lua-окружения. Это не запущенный игровой клиент.
Стенд: tests/validate.py и tests/wow_mock.lua в рабочей папке разработки.
В ZIP аддона стенд и его зависимости не включены.

ДОБАВЛЕНИЕ 1.2.4
Внешняя проверка последнего стабильного GitHub Release через Windows
PowerShell 5.1. Адрес публичного репозитория задаётся при первом запуске
Check-Updates.cmd и сохраняется в UpdateConfig.json. Результат атомарно
записывается в UpdateStatus.lua и загружается игрой при входе или /reload.
/scw update показывает результат с датой; новая версия по свежей проверке
также сообщается при входе. Результат старше суток не считается актуальным.
Start-ChatWheel.cmd проверяет настроенный GitHub перед запуском игры.
Ни скачивание, ни установка кода этой проверкой не выполняются.

ПРОВЕРКИ ОБНОВЛЕНИЙ
- Числовое сравнение X.Y.Z, включая 1.10.0 > 1.9.9.
- Первый запуск без адреса; сохранение и повторное чтение адреса.
- Преобразование URL https://github.com/OWNER/REPO.git в OWNER/REPO.
- Внешний PowerShell получает имитированный ответ REST API, результат
  исполняется настоящим Lua 5.1 в полном загрузочном наборе аддона.
- Уведомление о новой версии локальное, без чата, звука и сетевых пакетов WoW.
- Совпадение версий не вызывает автоматическое уведомление.
- Ручной показ содержит дату; устаревший результат не выдаётся за свежий.
- Ошибка сети перезаписывает прежний успех состоянием failed.
- Нестандартный тег с Lua-кодом, prerelease и адрес вне github.com отклоняются.
- Проверка не меняет Core.lua, Catalog.lua, SoundNames.json и исходные WAV.
- Отдельная живая проверка HTTPS выполнена в временной папке на публичном
  репозитории PowerShell/PowerShell: API ответил, файл результата сформирован.
  Этот адрес использовался только для теста; он не настроен в рабочем аддоне.
- Собственного репозитория SirusChatWheel в этой сессии ещё нет; его публикация
  и проверка именно его Releases пока не выполнялись.

ИСПРАВЛЕНИЕ 1.2.3 (СОХРАНЕНО)
До изменения стенд воспроизвёл два сбоя /say:
1. Отправитель хранил только последнюю принятую звуковую фразу. Если две
   фразы были отправлены до получения скрытого запроса на первую,
   первая фраза уже не могла получить подтверждение.
2. Получатель отбрасывал второе название от одного игрока в течение
   секунды, хотя лимит допускает два звука подряд.
После изменения сохраняются все принятые действия за последние шесть
секунд. Получатель допускает два запроса обнаружения за скользящую секунду.
Формат скрытых сообщений SCW12 не менялся. Для исправления обеим сторонам
нужна версия 1.2.3; старые версии сохраняют свои прежние ограничения.

ПРОВЕРЕННЫЕ СЦЕНАРИИ
- Загрузка файлов TOC, ADDON_LOADED, PLAYER_LOGIN и назначение Y.
- Восемь направлений, зона отмены, движение относительно исходного курсора.
- Выполнение Bindings.xml при нажатии и отпускании, отправка в /raid.
- Повторная выборка положения мыши на отпускании, восстановление курсора.
- Проверка без отправки, открытое поле ввода, работа колеса в бою,
  отмена щелчком мыши.
- Ровно 12 текстовых вариантов перед голосовыми в списке выбора.
- Восемь подписей с размером шрифта x1,4, отсутствие нижней инструкции.
- Отдельный динамик слева с привязкой к вертикальному центру подписи.
- Применение настроек и восстановление значений по умолчанию.
- Два звука разрешены; третий даёт только красную ошибку, без чата,
  скрытого сообщения и звука. Каждая отправка истекает отдельно.
- Сброс настроек и сохранение не обнуляют лимит.
- /raid: скрытый пакет запускает звук у другого окружения игрока;
  повтор пакета и отправитель вне рейда отвергаются.
- Отключение приёма голосовых фраз.
- Простое название в чате не запускает аудио.
- /say: две разные записи при задержанных подтверждениях;
  две быстрые записи; два повтора одной записи; повтор скрытых ответов;
  отказ подтверждать действие старше шести секунд.
- Ошибка отправки чата откатывает лимит и историю подтверждений,
  не отправляет скрытый пакет и не проигрывает запись.
- Настоящий Windows PowerShell 5.1 создаёт каталог в временной копии.
- MP3 с расширением .MP3, русским именем и подпапкой принимается Lua 5.1.
  Для этой проверки используются синтетические MPEG-фреймы: декодирование
  звука не проверяется. Неподдерживаемое расширение .exe не включается.
- Название из JSON с кавычками и обратными слешами корректно проходит Lua.
- Кэш побайтно совпадает с исходным файлом; SoundNames.json не меняется.
- Переименование удаляет прежнюю запись и кэш, назначенный слот пустеет;
  удаление исключает запись из каталога. Исходный WAV остаётся неизменным.

СБОРКА И СОХРАННОСТЬ ФАЙЛОВ
Полный ZIP предназначен для новой установки. ZIP с окончанием -update
не содержит Sounds, SoundNames.json, Catalog.lua и Media/Cache, поэтому
не заменяет их при распаковке поверх существующей установки.
В рабочем аддоне эти файлы сохранены из исходного архива 1.2.2.
Утилита SoundCatalog.ps1 и пользовательские звуки не изменялись.
Настройки сохраняются через SavedVariables: SirusChatWheelDB.

ПРЕДЕЛЫ ПРОВЕРКИ
Sirus в среде разработки недоступен. Не проверены фактическое скрытие
аппаратного курсора, визуальная компоновка в игре, декодирование MP3/OGG,
защищённые пути исполнения и разрешение служебного шёпота сервером Sirus.
После установки нужны /scw test и проверка голосовой фразы вторым игроком
с одинаковыми файлами. Для изменения состава звуков нужен
Update-Sounds.cmd, затем /reload.
Публикация на GitHub не выполнялась. URL репозитория SirusChatWheel пока не задан.
