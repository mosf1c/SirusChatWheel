Добавлены три голосовые фразы:

- **Старый Бог**
- **Скорую! Скорую! ВРАЧА!**
- **Да нет, друг, я не оправдываюсь**

Громкость новых записей выровнена с существующим набором. Всего в выпуске шесть голосовых фраз.

Все голосовые сообщения теперь публикуются в чате в угловых скобках, например `<Старый Бог>`. Синхронизация через скрытые сообщения аддона, мут игроков и лимит двух звуков за 30 секунд сохранены. Получение старого формата без скобок также поддерживается.

Скачайте **SirusChatWheel-1.5.0.zip** ниже. Закройте игру и перенесите папку `SirusChatWheel` из архива в `Interface\AddOns` с заменой файлов. Один архив подходит для первой установки и обновления; все звуки, каталог и кэш уже внутри. Настройки в `WTF` сохраняются. Новые записи выберите в `/scw` → «Фразы».

Для новых звуков и обмена через `/say` с сообщениями в скобках другим игрокам тоже нужен этот выпуск.

Архивы **Source code** содержат исходники для разработки. Для игры используйте **SirusChatWheel-1.5.0.zip**.

213 автоматических проверок выполнены на Lua 5.1 и PowerShell 5.1 с имитацией API WoW. Проверка в настоящем клиенте Sirus ещё требуется.
