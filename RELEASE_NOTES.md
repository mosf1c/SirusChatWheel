В готовом архиве теперь **одна копия каждого звука**. Рабочие исходники и `SoundNames.json` остаются в репозитории автора; игрок получает готовые файлы в `Media\Cache` и каталог. Набор из шести голосовых фраз и их громкость сохранены.

Служебная история входящих команд ограничена по объёму и времени. Отклонённые команды больше не обновляют список игроков. Ограничены также ожидающие подтверждения `/say`.

В правом нижнем углу настроек добавлена подпись **by mosf1c**.

Скачайте **SirusChatWheel-1.5.1.zip** ниже.

**При переходе с 1.5.0 или более старой версии:** закройте игру, удалите только старую папку `Interface\AddOns\SirusChatWheel` и перенесите на её место папку из нового архива. Это разовое действие уберёт старые дубли: простое копирование поверх оставляет прежнюю папку `Sounds` на диске. Настройки секторов, канал и мут сохранятся в `WTF`; эту папку не удаляйте.

Для первой установки достаточно перенести папку `SirusChatWheel` из архива в `Interface\AddOns`. Каталог уже готов, дополнительные утилиты запускать не требуется.

Архивы **Source code** предназначены для разработки. Для игры используйте **SirusChatWheel-1.5.1.zip**.

244 автоматические проверки выполнены на Lua 5.1 и PowerShell 5.1 с имитацией API WoW. Проверка в настоящем клиенте Sirus ещё требуется.
