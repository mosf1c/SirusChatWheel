Добавлена вкладка **«Игроки»**: недавние отправители с последней голосовой фразой, заглушение по кнопке или нику и список с возможностью вернуть звук. Мут действует сразу, очищает ожидающие записи этого игрока и сохраняется между запусками. Текст в чате остаётся видимым.

Включена фраза **«Короля не убить»**. Громкость всех трёх записей выровнена.

Скачайте **SirusChatWheel-1.4.0.zip** ниже. Закройте игру и перенесите папку `SirusChatWheel` из архива в `Interface\AddOns` с заменой файлов. Один архив подходит для первой установки и обновления; все звуки, каталог и кэш уже внутри. Настройки в `WTF` сохраняются.

Архивы **Source code** содержат исходники для разработки. Для игры используйте **SirusChatWheel-1.4.0.zip**.

Автоматические проверки выполнены на Lua 5.1 и PowerShell 5.1 с имитацией API WoW. Проверка в настоящем клиенте Sirus ещё требуется.
